# Definition of Ready (DoR) Checklist

To pass the Phase 1 gate, the requirement MUST satisfy the **INVEST** principles:

- **Independent**: The story can be developed/tested without tight coupling to other open sprints.
- **Negotiable**: The user and agent can discuss the scope before implementation.
- **Valuable**: It delivers clear value to the end-user or business.
- **Estimable**: The Architect (Phase 2) must be able to judge the effort required.
- **Small**: The scope must fit within a single execution cycle.
- **Testable**: There must be clear, objective ways to verify success (see Gherkin).

**Mandatory Fields for "Ready" Status:**
1. Clear User Role (As a...)
2. Actionable Intent (I want to...)
3. Justified Value (So that...)
4. At least 3 Functional ACs (Given/When/Then)
