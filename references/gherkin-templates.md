# Gherkin Formatting Standards

### User Story Format
> **As a** [user type]
> **I want to** [specific action]
> **So that** [derived benefit/value]

### Acceptance Criteria (Functional)
Every functional behavior must follow this syntax:
- **Given** [pre-condition or state]
- **When** [specific action triggered by user]
- **Then** [expected outcome or change in state]

### Non-Functional Requirements (Checklist)
- [ ] Performance: Must respond within [X]ms.
- [ ] Security: Must require [Y] level of authorization.
- [ ] Logging: Must write outcome to `log.md`.
