## Acceptance Criteria

### US.4 — Search Recipes by Name

```gherkin
AC-1: Search filters list by matching title
  Given at least two recipes are saved with different titles
  When  the user types a partial name in the search box
  Then  only recipes whose title contains the search text (case-insensitive) are shown

AC-2: Empty search shows all recipes
  Given recipes are saved and a search term was previously entered
  When  the user clears the search box
  Then  all recipes are displayed again

AC-3: Search with no match shows empty state
  Given recipes are saved
  When  the user types a name that matches no recipe
  Then  a "No recipes match your search" message is shown
```

### US.6 — Dark Mode Toggle

```gherkin
AC-4: Dark mode toggles on
  Given the app is in light mode
  When  the user clicks the Dark Mode toggle
  Then  the page switches to a dark colour scheme

AC-5: Dark mode preference persists after reload
  Given the user has enabled dark mode
  When  the user reloads the page
  Then  dark mode is still active

AC-6: Light mode restores on second toggle
  Given dark mode is active
  When  the user clicks the toggle again
  Then  the page returns to light mode
```
