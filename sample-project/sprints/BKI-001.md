## Acceptance Criteria

### US.1 — Save a Recipe

```gherkin
AC-1: Save recipe with all fields
  Given the user is on the recipe form
  When  the user enters Title, Ingredients, and Instructions and clicks Save
  Then  the recipe appears in the recipe list
  And   the data persists after page reload (LocalStorage)

AC-2: Save blocked when required field missing
  Given the user is on the recipe form
  When  the user leaves Title empty and clicks Save
  Then  an inline validation error "Title is required" appears
  And   no recipe is added to the list
```

### US.2 — View Recipe List

```gherkin
AC-3: List shows all saved recipes
  Given at least one recipe is saved
  When  the user opens the app
  Then  all saved recipes are displayed with their Title visible
  And   the list loads without console errors

AC-4: Empty state shown when no recipes
  Given no recipes are saved
  When  the user opens the app
  Then  an empty-state message is shown (e.g. "No recipes yet")
```

### US.3 — Delete a Recipe

```gherkin
AC-5: Delete removes recipe from list and storage
  Given a recipe exists in the list
  When  the user clicks Delete on that recipe
  Then  the recipe is removed from the list immediately
  And   the recipe is no longer present after page reload

AC-6: Delete requires confirmation
  Given a recipe exists in the list
  When  the user clicks Delete
  Then  a confirmation prompt appears before deletion
  And   cancelling leaves the recipe intact
```
